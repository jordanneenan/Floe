# Floe brand assets

- `floe-logo.svg` is the full header lockup: two outlined blocks and two solid dots arranged as website modules, paired with a lowercase Geist Medium wordmark. The mark runs from the wordmark's baseline to its ascender, and its outline weight is matched to the letters. The wordmark is outlined from Geist with tightened letter spacing, so the SVG has no runtime font dependency. Colour is Ink (`#0B1220`).
- `floe-mark.svg` is the standalone mark for future uses.
- `floe-site-icon.svg` is the mark on a dark tile. `floe-site-icon.png` is its 512 px export for WordPress's native Site Icon setting.

The header uses the full SVG when no WordPress custom logo is set. A custom logo replaces it through WordPress's existing setting. The LocalWP Floe site uses the PNG as its Site Icon.
