# Floe preview imagery

These five generated architectural photographs are temporary content for the Floe block preview in LocalWP. They are media-library content, not baked-in block defaults, so a site can replace them without changing the theme.

The WebP files preserve the generated 1536 × 1024 compositions and are named for their subjects. The LocalWP preview page uses them across banners, cards, image rows, and the video cover. The source artwork was generated for this Floe project in September 2026.
