# Floe preview imagery

Placeholder content for the preview site, not client content and not block defaults.

- **Photos** (floe-hero, floe-dawn, floe-drift, floe-seam, floe-blue, floe-giant, floe-pack-teal, floe-dusk) are **not** in the repository. Upload them to the media library, or pass their folder to the seed script: `wp eval-file wp-content/themes/floe/scripts/seed-preview.php /path/to/images`. Patterns find them by file name, so any site with those files uploaded gets the same preview. (Decision D16.)
- **`logos/`**: six placeholder client wordmarks (Northwind, halcyon, MERIDIAN, Arbor & Co, Kestrel, lumen°) set in Geist to match the Figma Logo strip. Transparent PNGs, so the Logo strip shows them in one muted tone. The seed script uploads them.
- **Documents** for Document Download are generated by the seed script (small placeholder PDFs and an XLSX).

The architectural WebP set used by the first-generation preview was removed in phase 6.
