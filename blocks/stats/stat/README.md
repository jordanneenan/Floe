# Stat (`floe/stat`)

One figure in **Stats**: optional prefix, value, optional unit (accent colour, sits on the value's baseline) and label. Nothing renders if the value is empty.

**Prefix** (block settings) goes before the number at the same size and colour, e.g. `£`, `$` or `~`. It's kept apart from the value so the Stats **Count up** animation ticks only the number (`£0` → `£250`).
