# Stats (`floe/stats`)

Two to four figures (Figma `43:235`). For an eyebrow, heading and intro, add a **Block intro** above the Stats.

| Field | Notes |
| --- | --- |
| Stats | Two to four **Stat** blocks: value (Display), optional unit in the accent colour (e.g. `+`, `%`, `wks`), label. |

For a coloured band, put the Stats and their Block intro in a **Background** block.

**Responsive:** one row of equal columns from 768px; two-up below that.

**Components used:** none (Stat markup only).
