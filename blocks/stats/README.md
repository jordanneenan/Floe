# Stats (`floe/stats`)

Two to four figures (Figma `43:235`). For an eyebrow, heading and intro above them, put the Stats in an **Intro** block (layout: heading above).

| Field | Notes |
| --- | --- |
| Stats | Two to four **Stat** blocks: value (Display), optional unit in the accent colour (e.g. `+`, `%`, `wks`), label. |

The section is on the Base surface; inside an Intro, the Intro's surface is used instead.

**Responsive:** one row of equal columns from 768px; two-up below that.

**Components used:** none (Stat markup only).
