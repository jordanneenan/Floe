# Stats (`floe/stats`)

A heading group and two to four figures (Figma `43:235`).

| Field | Notes |
| --- | --- |
| Eyebrow, Heading, Intro | Section header. |
| Stats | Two to four **Stat** blocks: value (Display), optional unit in the accent colour (e.g. `+`, `%`, `wks`), label. |

**Responsive:** one row of equal columns from 768px; two-up below that.

**Components used:** Section header.
