# Team (`floe/team`)

A heading group and a grid of people (Figma `44:317`).

| Field | Notes |
| --- | --- |
| Eyebrow, Heading, Intro | Section header. |
| People | **Person** blocks: portrait (4:5), name, role. |

**Responsive:** 4-up from 768px, 2-up on tablet, 1-up on mobile.

**Later decision for Jordan:** Figma suggests backing this with a Team content type in a plugin so people survive a theme change. For now people are entered in the block.

**Components used:** Section header, Media.
