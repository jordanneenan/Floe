# Testimonial (`floe/testimonial`)

One long quote (Figma `35:76`). For several short quotes use Testimonials.

| Field | Notes |
| --- | --- |
| Quote | Large text (40/50 on desktop, scales down). The quote mark is added automatically. |
| Name, Role | Attribution. |
| Portrait | Optional small round image (sidebar or the slot beside the name). When there's no portrait, no space is reserved for it. |

For the Figma look, put it in a **Background** block set to Subtle. The block renders nothing if the quote is empty.

**Components used:** Media.
