# Image + Copy (`floe/image-copy`)

Media beside a short story (Figma `34:94`).

| Field | Notes |
| --- | --- |
| Media | Image or looping MP4 (624×560 at 1440). If none is set, the copy sits in a single 860px column. |
| Switch side | Tick it in the block settings to put the image on the right and the text on the left (the block toolbar has the same choice). Stack several Image + Copy blocks and tick every other one for alternating rows. |
| Eyebrow, Heading, Body | Heading level H2 by default (sidebar: H2–H4). Body is Body L, muted. |
| Action | Optional Primary button. |

For a coloured band, put it in a **Background** block.

**Responsive:** below 768px the media stacks above the copy (whichever side it's set to).

**Components used:** Eyebrow, Button, Media.
