# Testimonials (`floe/testimonials`)

**Figma:** design [44:221](https://www.figma.com/design/F43LfH93WZls4WkgIo5e3n?node-id=44-221), [102:1229](https://www.figma.com/design/F43LfH93WZls4WkgIo5e3n?node-id=102-1229) · dark [91:904](https://www.figma.com/design/F43LfH93WZls4WkgIo5e3n?node-id=91-904) · wireframe [46:1096](https://www.figma.com/design/F43LfH93WZls4WkgIo5e3n?node-id=46-1096)

Several short quotes as cards (Figma `44:221`). For one long quote use Testimonial. For an eyebrow and heading, add a **Block intro** above the Testimonials.

| Field | Notes |
| --- | --- |
| Quotes | **Quote card** blocks: quote, name, role, optional round portrait (neutral placeholder when empty). |

**Grid or slider:** up to three quotes sit in a grid. With four or more the page shows a slider: previous/next buttons appear in a row below the cards, on the right (they disable at either end), and the row can also be swiped or scrolled with a trackpad or keyboard. In the editor every card stays visible in a wrapping grid so each can be edited.

**Responsive:** the grid stacks below 768px. The slider shows ~1.2 cards on mobile, 2 on tablet and 3 on desktop.

**Decision:** Figma has the quote touching the attribution; there's a 32px minimum gap here.

For a coloured band, put the Testimonials and their Block intro in a **Background** block.

**Components used:** Media, Icon.
