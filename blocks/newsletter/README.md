# Newsletter (`floe/newsletter`)

A tint panel with a signup form (Figma `45:363`).

| Field | Notes |
| --- | --- |
| Eyebrow, Heading, Intro | Stacked heading group (Body intro). |
| Form slot | Floe's **Form** block (Newsletter signup), or your mailing provider's block or a Shortcode block. A single email field and submit button sit on one line; the button matches the 52px field. |
| Button | Only when the form slot is empty: turns the panel into a **slimmer CTA** (as the Figma description suggests). |
| Note | Optional small line, e.g. a privacy note. |

**Responsive:** below 768px the form sits under the copy.

**Components used:** Section header, Button, Form (styles).
