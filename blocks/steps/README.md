# Steps (`floe/steps`)

A numbered, connected sequence of three to five steps (Figma `43:263`). For an eyebrow, heading and button (e.g. "See the full process", a Secondary button on the right), put the Steps in an **Intro** block (layout: heading above).

| Field | Notes |
| --- | --- |
| Steps | Three to five **Step** blocks (title, text). Step titles are one level below the Intro's heading (H3 by default). Numbers (01, 02…) are added automatically; the first marker is filled blue. |
| Surface | Subtle (default), Base or Tint. Inside an Intro, the Intro's surface is used instead (set the Intro to Subtle for the Figma look). |

**Responsive:** a horizontal track from 768px. Below that the steps stack vertically with the connecting line running down the left.

**Decision:** in Figma the markers drift left of their text columns (by 8, 16 and 24px); here each marker lines up with its column.

**Components used:** none (Step markup only).
