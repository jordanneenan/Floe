# Steps (`floe/steps`)

A numbered, connected sequence of three to five steps (Figma `43:263`). For an eyebrow, heading and button (e.g. "See the full process", a Secondary button on the right), add a **Block intro** above the Steps.

| Field | Notes |
| --- | --- |
| Steps | Three to five **Step** blocks (title, text). Step titles are H3. Numbers (01, 02…) are added automatically; the first marker is filled blue. |

For the Figma look, put the Steps and their Block intro in a **Background** block set to Subtle.

**Responsive:** a horizontal track from 768px. Below that the steps stack vertically with the connecting line running down the left.

**Decision:** in Figma the markers drift left of their text columns (by 8, 16 and 24px); here each marker lines up with its column.

**Components used:** none (Step markup only).
