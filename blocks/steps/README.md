# Steps (`floe/steps`)

A numbered, connected sequence of three to five steps (Figma `43:263`).

| Field | Notes |
| --- | --- |
| Eyebrow, Heading | Section header. |
| Action | Optional Secondary button on the right (e.g. "See the full process"). |
| Steps | Three to five **Step** blocks (title, text). Numbers (01, 02…) are added automatically; the first marker is filled blue. |
| Surface | Subtle (default), Base or Tint. |

**Responsive:** a horizontal track from 768px. Below that the steps stack vertically with the connecting line running down the left.

**Decision:** in Figma the markers drift left of their text columns (by 8, 16 and 24px); here each marker lines up with its column.

**Components used:** Section header, Button.
