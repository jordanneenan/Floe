# CTA panel (`floe/cta-panel`)

One panel inside **CTA**.

| Field | Notes |
| --- | --- |
| Surface | Ink (Inverse, default), Accent (blue), Tint or Subtle. Text, eyebrow and button colours follow automatically. |
| Eyebrow, Heading, Body | Heading is an H2 by default (sidebar: H2–H4); its size follows the layout. |
| Action | One button. |
| Note | Optional small line, e.g. "or email hello@studio.com" (links allowed). |
| Image | Optional, 16:9, at the top of the panel (sidebar). |

A panel with no heading and no button renders nothing.
