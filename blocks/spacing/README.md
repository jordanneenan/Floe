# Spacing (`floe/spacing`)

A gap between two sections. Every section has its own top and bottom padding; placing Spacing between two sections removes the padding on the edges facing the gap, so the space is exactly the size chosen here.

**Fields**

| Field | Notes |
| --- | --- |
| Size | Large, Medium, Small or No space. |
| Set exact values per screen size | Enter pixel values for large desktop (1280+), desktop (768–1279), tablet (550–767) and mobile (<550). Empty fields use the preset. Max 500. |

**Preset values** (large desktop / desktop / tablet / mobile): Large 120 / 120 / 86 / 67, Medium 80 / 80 / 57 / 44, Small 40 / 40 / 29 / 22. Tablet and mobile follow Made's ÷1.4 and ÷1.8 ratios.

**Editing notes:** In the editor the gap shows as a dashed blue area so it can be selected. "No space" joins two sections edge to edge.

**Components used:** none.
