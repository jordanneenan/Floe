# Spacing (`floe/spacing`)

A gap below a block. Every block has a margin below it (120px on large desktop, 96 desktop, 80 tablet, 64 mobile; smaller below a stacked Block intro). A Spacing block replaces the margin of the block above it, so the space is exactly the size chosen here.

**Fields**

| Field | Notes |
| --- | --- |
| Size | Large, Medium, Small or No space. |
| Set exact values per screen size | Enter pixel values for large desktop (1280+), desktop (768–1279), tablet (550–767) and mobile (<550). Empty fields use the preset. Max 500. |

**Preset values** (large desktop / desktop / tablet / mobile): Large 120 / 120 / 86 / 67, Medium 80 / 80 / 57 / 44, Small 40 / 40 / 29 / 22. Tablet and mobile follow Made's ÷1.4 and ÷1.8 ratios.

**Editing notes:** In the editor the gap shows as a dashed blue area so it can be selected. "No space" joins two blocks edge to edge, for example two Background blocks. Inside a Background with Auto spacing off, Spacing blocks at the top and bottom set the band's space.

**Components used:** none.
