# Cards (`floe/cards`)

A heading group and a grid of manually entered cards (Figma `36:173`).

| Field | Notes |
| --- | --- |
| Eyebrow, Heading, Intro | Section header. Heading level in the sidebar. |
| Card style | **Feature**: numbered cards (01, 02… added automatically in order), title, text and a "Learn more" link, on the raised surface colour. **Media**: an image or MP4 on each card, title and text; the card can link. |
| Cards | Add as many **Card** blocks as needed. |
| Surface | Base (default), Subtle or Tint. |

**Responsive:** three-up from 768px, two-up on tablet, one-up on mobile. The section renders nothing with no cards.

**Components used:** Section header, Card (and Media, Button through Card).
