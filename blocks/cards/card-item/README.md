# Card (`floe/card-item`)

One card in **Cards**. The parent's Card style decides how it looks.

| Field | Notes |
| --- | --- |
| Title, Text | Edited in place. The title is H3 (one level below the section heading). |
| Link | Toolbar link button. The title becomes the link and the whole card is clickable. Feature cards show a "Learn more" cue (the text can be changed in the link popover). |
| Media | Media style only: an image or MP4 (4:3). Empty shows the neutral placeholder. |

Feature card numbers (01, 02…) are added automatically in order.
