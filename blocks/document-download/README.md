# Document Download (`floe/document-download`)

A heading group beside a list of downloadable files (Figma `37:130`).

| Field | Notes |
| --- | --- |
| Eyebrow, Heading, Intro | Stacked heading group on the left. |
| Files | Add **Download** blocks: one file each from the media library (PDF, DOC/DOCX, XLS/XLSX, PPT/PPTX and others). |

Each row is a single link. Type and size are read from the media library; the title is the file's title unless overridden.

**Responsive:** below 768px the list sits under the heading group.

**Components used:** Section header, File row.
