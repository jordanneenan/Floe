# Document Download (`floe/document-download`)

A list of downloadable files (Figma `37:130`). For the eyebrow, heading and intro, put it in an **Intro** block with the two-column layout (heading beside the block), as in Figma.

| Field | Notes |
| --- | --- |
| Files | Add **Download** blocks: one file each from the media library (PDF, DOC/DOCX, XLS/XLSX, PPT/PPTX and others). |

Each row is a single link. Type and size are read from the media library; the title is the file's title unless overridden. The list is up to 760px wide with a line on top; beside an Intro heading it fills the right-hand column. The section is on the Base surface; inside an Intro, the Intro's surface is used instead. With no files it renders nothing.

**Responsive:** below 768px the Intro puts the list under its heading group.

**Components used:** File row.
