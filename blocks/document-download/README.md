# Document Download (`floe/document-download`)

A list of downloadable files (Figma `37:130`). For the eyebrow, heading and intro, put it in a **Block intro** set to Two columns (heading beside the list), as in Figma. A stacked Block intro above it also works.

| Field | Notes |
| --- | --- |
| Files | Add **Download** blocks: one file each from the media library (PDF, DOC/DOCX, XLS/XLSX, PPT/PPTX and others). |

Each row is a single link. Type and size are read from the media library; the title is the file's title unless overridden. The list is up to 760px wide with a line on top; in a two-column Block intro it fills the right-hand column. For a coloured band, put the Block intro (with the list) in a **Background** block. With no files it renders nothing.

**Responsive:** below 768px a two-column Block intro puts the list under its heading group.

**Components used:** File row.
