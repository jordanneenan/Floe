# Testimonials (`floe/testimonials`)

Several short quotes as cards (Figma `44:221`). For one long quote use Testimonial.

| Field | Notes |
| --- | --- |
| Eyebrow, Heading | Section header. |
| Quotes | **Quote card** blocks: quote, name, role, optional round portrait (neutral placeholder when empty). |

**Grid or slider:** up to three quotes sit in a grid. With four or more the page shows a slider: previous/next buttons appear in the header (they disable at either end), and the row can also be swiped or scrolled with a trackpad or keyboard. In the editor every card stays visible in a wrapping grid so each can be edited.

**Responsive:** the grid stacks below 768px. The slider shows ~1.2 cards on mobile, 2 on tablet and 3 on desktop.

**Decision:** Figma has the quote touching the attribution; there's a 32px minimum gap here.

**Components used:** Section header, Media, Icon.
