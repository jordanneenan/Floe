# Image row (`floe/image-row`)

One row inside **Images**: up to three **Media** blocks. The columns follow the number of items (one, two or three), so there are never empty columns.

| Field | Notes |
| --- | --- |
| Gap between items | On by default (24px). Off joins the items edge to edge in one rounded frame. |

**Responsive:** a three-item row stacks below 550px.
